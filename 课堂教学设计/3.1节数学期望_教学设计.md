## 三、教学理念
遵循“从统计平均到概率抽象”的认知规律。对于理科学生而言，虽然他们已在力学中熟悉了“质心”概念，但在处理随机现象时，往往缺乏一种宏观的“特征提取”思维。本节课的核心理念是将数学期望从简单的“算术平均”升华为“加权平均”的极限，并与物理中的“质心（Center of Mass）”建立深刻映射。通过引入“验血分组（Pooled Testing）”和“柯西分布期望不存在”等反常案例，打破学生对“期望必存在”的固有刻板印象，培养其严谨的数学分析与建模能力。

## 四、教学目标
**1、知识目标**
- 掌握离散型随机变量数学期望的级数定义（绝对收敛）。
- 掌握连续型随机变量数学期望的反常积分定义（绝对收敛）。
- 掌握二维随机变量边缘分布与联合分布求期望的两种等价方法。

**2、能力目标**
- 能够将实际生活或工程中的优化问题（如分组验血降低成本）转化为数学期望的极值问题，并利用微积分工具求解。
- 能够利用质心概念，直观判断对称分布的数学期望。

**3、素质目标**
- 通过引入“二战期间美军梅毒抽血筛查”的真实历史案例，展示数学期望在优化社会资源配置中的巨大威力，培养学生用数学解决国家重大需求的家国情怀与工程素养。
- 深刻理解“绝对收敛”条件的必要性（柯西分布的期望灾难），建立对无限过程的数学敬畏感。

## 五、学情分析
- **专业背景**：授课对象为物理与天文学大二学生，具备扎实的微积分基础，对“质心”、“加权平均”有物理直觉。
- **知识基础**：已在前两章熟练掌握了随机变量的分布列、概率密度、联合分布及边缘分布。
- **认知难点**：
  1. 为什么期望必须要求“绝对收敛”？（学生往往认为只要是对称分布，期望就是对称中心，难以理解无穷积分的正负抵消问题）。
  2. 离散型分组验血案例中，构建“需要化验的次数”这一随机变量并求其分布列，对学生的建模能力要求较高。

## 六、教学内容
1. **数学期望的引入**：射击成绩的比较（从算术平均到以概率为权的加权平均）。
2. **离散型随机变量的数学期望**：有限项与无穷级数（强调绝对收敛）。
3. **经典建模案例**：分组验血方案的最优化设计。
4. **连续型随机变量的数学期望**：反常积分定义及“质心”物理意义。
5. **期望不存在的反例**：柯西分布（Cauchy Distribution）。
6. **二维随机变量的数学期望**：利用边缘分布或直接利用联合分布（双重积分/双重级数）。

## 七、教学重点及难点
**重点内容**
- 数学期望的“加权平均”本质。
- 分组验血案例的建模全过程（构建变量 $\rightarrow$ 写分布列 $\rightarrow$ 求期望 $\rightarrow$ 求导找极值）。

**解决措施**
- **情境代入法**：将枯燥的数学推导包装为“你作为二战军医，如何用最少的试剂筛查10万新兵”的挑战任务，激发求解欲。

**难点内容**
- 柯西分布数学期望不存在的证明与理解。

**解决措施**
- **极限拆解法**：在黑板上严格写出 $\lim_{R \to \infty} \int_0^R \frac{x}{1+x^2}dx$ 与 $\lim_{R \to \infty} \int_{-R}^0 \frac{x}{1+x^2}dx$，让学生看到 $\infty - \infty$ 属于未定式，从而说明如果没有“绝对收敛”的保护，积分值将依赖于正负方向趋于无穷的速度，导致期望值不唯一（无意义）。

## 八、教学方法与教学工具运用
- **教学方法**：案例驱动法、物理类比法（质心）、反证法（柯西分布）。
- **教学工具**：黑板（推导验血成本极值、证明柯西积分发散）、PPT（展示射击成绩柱状图对比、验血分组示意图）。

## 九、教学特色与创新
- **历史真实案例的深度剖析**：本节课选用的“分组验血”案例不仅是教材例题，更是运筹学历史上的经典之作（Dorfman, 1943）。通过还原该问题的历史背景，将单纯的“算期望”升格为“运筹优化”，极大地拓展了概率论的工程应用视野。
- **数学严谨性与物理直觉的交锋**：一方面用物理上的“质心”建立直觉；另一方面用“柯西分布”摧毁直觉（看起来对称，但没有质心！），在“建立-打破”中重塑学生的微积分认知底线。

## 十、课前任务设计（教师和学生的教学准备）
- **教师准备**：查阅 Dorfman 分组验血（Pooled Testing）的历史文献；准备柯西分布无期望的直观演示（如使用 Python 模拟大量柯西随机数并求平均，发现平均值永远不会收敛的“灾难现象”）。
- **学生准备**：复习大一高等数学中的“绝对收敛”级数和反常积分；回顾第一章的独立性概念。

## 十二、过程性评价（设计评价细则与课程目标对应关系图）

**1. 课堂提问清单（对应知识/能力目标）**
- **提问1**：“如果某地人群感染率 $p=0.5$，还能不能用分组验血法降低成本？”（考察对模型参数敏感性的直觉。答案：不能，因为 $q^k = 0.5^k$ 会变得很小，$1-q^k$ 会很大，几乎每组都要二次化验，反而增加了成本。学生可通过解方程验证这一点）。
- **提问2**：“二维连续随机变量 $(X,Y)$，已知 $X$ 和 $Y$ 是独立的。求 $E(X)$ 时，联合分布公式里的 $f(x,y)$ 可以替换成什么？”（考察对上章独立性的调用。答案：替换成 $f_X(x)f_Y(y)$，积分即可分离）。

**2. 当堂小测验（对应期望计算能力）**
- **测验题**：设连续随机变量 $X$ 的概率密度为 $f(x) = \lambda e^{-\lambda x} \ (x>0)$，求其数学期望 $E(X)$。
  （**考察点**：利用分部积分法计算反常积分 $\int_0^\infty x \lambda e^{-\lambda x}dx$，答案为 $1/\lambda$。这是指数分布最重要的特征，为后续课程做铺垫）。

## 十三、课后作业

**【基础巩固题】（必做，熟练掌握期望的积分与级数计算）**
1. **（离散期望）** 设随机变量 $X$ 服从参数为 $\lambda$ 的泊松分布 $P(\lambda)$，求其数学期望 $E(X)$。（提示：利用泰勒展开式 $e^\lambda = \sum \frac{\lambda^k}{k!}$）。
2. **（连续期望）** 设随机变量 $X$ 服从均匀分布 $U(a, b)$，求其数学期望 $E(X)$，并说明其物理意义。
3. **（二维期望）** 设二维随机变量 $(X,Y)$ 在区域 $D: 0 < x < 1, 0 < y < x$ 上服从均匀分布。求 $E(X)$ 和 $E(Y)$。（要求：直接用联合密度双重积分计算）。

**【能力提升题】（选做，经济决策建模）**
4. **（报童问题）** 某报童每天以 0.5 元的价格买进报纸，以 1.0 元的价格卖出。如果当天卖不掉，只能以 0.1 元的价格当废纸回收。已知每天报纸的需求量 $X$ 是一个随机变量，其分布列如下：
   | $X$ (份) | 100 | 150 | 200 | 250 |
   |---|---|---|---|---|
   | $p_i$ | 0.2 | 0.4 | 0.3 | 0.1 |
   问：报童每天应该进货多少份报纸，才能使他当天的**预期利润（利润的数学期望）**达到最大？（提示：设进货量为 $N$，列出利润 $Y$ 与 $X$ 的函数关系，再求 $E(Y)$）。

**【素养拓展题】（选做，Python蒙特卡洛验证柯西分布）**
5. **（柯西分布的崩溃）**
   (1) 编写 Python 代码，利用 `numpy.random.standard_cauchy(size)` 生成 10 万个柯西分布的随机数。
   (2) 计算前 $n$ 个数的**累积平均值**，并绘制这 10 万个累积平均值随 $n$ 变化的折线图。
   (3) 与标准正态分布的累积平均值图进行对比。你观察到了什么震撼的现象？这印证了课堂上讲的什么理论？

### 【附录：课后作业参考答案】
1. $E(X) = \sum_{k=0}^\infty k \frac{\lambda^k e^{-\lambda}}{k!} = \lambda e^{-\lambda} \sum_{k=1}^\infty \frac{\lambda^{k-1}}{(k-1)!} = \lambda e^{-\lambda} e^\lambda = \lambda$。
2. $E(X) = \int_a^b x \frac{1}{b-a} dx = \frac{1}{b-a} [\frac{1}{2}x^2]_a^b = \frac{b^2-a^2}{2(b-a)} = \frac{a+b}{2}$。物理意义是均匀线段的几何中心。
3. 区域面积 $S = 1/2$，联合密度 $f(x,y) = 2$。
   $E(X) = \int_0^1 dx \int_0^x x \cdot 2 dy = \int_0^1 2x^2 dx = \frac{2}{3}$。
   $E(Y) = \int_0^1 dx \int_0^x y \cdot 2 dy = \int_0^1 x^2 dx = \frac{1}{3}$。
4. 设进货 $N$ 份。利润 $Y = 1.0 \min(X, N) + 0.1 \max(N-X, 0) - 0.5 N$。
   计算可知：
   $N=100$ 时，$E(Y) = 50$ 元；
   $N=150$ 时，$E(Y) = 1.0(100\times0.2 + 150\times0.8) + 0.1(50\times0.2) - 75 = 66$ 元；
   $N=200$ 时，$E(Y) = 1.0(100\times0.2 + 150\times0.4 + 200\times0.4) + 0.1(100\times0.2 + 50\times0.4) - 100 = 64$ 元；
   $N=250$ 时，$E(Y) = 1.0(E(X)) + 0.1(E(250-X)) - 125 = 45$ 元。
   因此，进货 150 份时预期利润最大（66元）。
5. 略（Python 模拟显示正态分布均值迅速收敛到0，而柯西分布的均值会不断发生巨大的跳跃，永远不收敛）。
