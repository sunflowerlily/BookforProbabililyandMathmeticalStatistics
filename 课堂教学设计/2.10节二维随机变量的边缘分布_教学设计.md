## 三、教学理念
遵循“从降维打击到信息不对称”的哲学与数学认知规律。对于物理和天文学，我们常常只能观测到复杂系统在某一个维度上的投影（如三维天体在二维照片上的投影，或双星系统中一颗恒星的独立光谱）。本节课的核心理念是让学生理解：边缘分布本质上就是联合分布在某一坐标轴上的“投影（降维）”。同时，深刻认识到“降维会丢失信息”（由边缘分布无法反推联合分布），从而体会联合分布描述系统内在“纠缠与联系”的不可替代性。

## 四、教学目标
**1、知识目标**
- 掌握二维**离散随机变量的边缘概率函数** $p_X(x_i)$ 和 $p_Y(y_j)$ 的计算方法（行列求和）。
- 熟练掌握二维**连续随机变量的边缘概率密度** $f_X(x)$ 和 $f_Y(y)$ 的计算方法（对另一个变量积分：$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)dy$）。
- 深刻理解“已知联合分布可以求边缘分布，但已知边缘分布通常无法唯一确定联合分布”的结论。

**2、能力目标**
- 提升学生的**积分技巧与图像划分能力**。特别是在求连续边缘密度时，能够根据联合密度非零区域的边界（如抛物线、斜线），准确画出图形并分段写出积分的上下限。
- 能够将多维物理问题（如二维位置分布）转化为单维物理问题（如仅看X方向的概率分布）。

**3、素质目标**
- 通过“全息图（联合分布）与投影图（边缘分布）”的类比，培养学生在科学研究中“不因局部而妄断整体”的系统观和批判性思维。

## 五、学情分析
- **专业背景**：授课对象为大二理科生，具备良好的微积分和二重积分基础，对“投影”、“截面”等空间几何概念有直观的物理认识。
- **知识基础**：在上一节（2.9节）刚刚学习了二维联合分布与联合密度，对 $f(x,y)$ 的体积意义有深刻印象。
- **认知难点**：
  1. 在计算连续边缘密度 $f_X(x)$ 时，学生常常忘记这是在**对 $y$ 积分**，容易在积分上下限中错误地混入 $y$。
  2. 当积分区域形状不规则（如教材例3中的抛物线区域）时，学生在分段求 $f_Y(y)$ 时极易找错不同区间的积分上下限。

## 六、教学内容
1. 二维离散边缘分布的概念及计算（行列求和法）。
2. 二维连续边缘分布函数 $F_X(x) = F(x, +\infty)$ 及其微积分关系。
3. 二维连续边缘密度函数公式 $f_X(x) = \int_{-\infty}^{+\infty} f(x,y) dy$（核心公式）。
4. 深度研讨：从联合分布可以推导边缘分布，但从边缘分布不能反推联合分布（以带有参数 $\lambda$ 的指数分布为例）。
5. 典型案例计算：区域边界为抛物线的边缘密度求解（强调分段积分的技巧）。

## 七、教学重点及难点
**重点内容**
- 连续随机变量**边缘概率密度的积分计算公式**（“要求谁，就不积谁；不求谁，就把谁积掉”）。

**解决措施**
- **口诀记忆与几何直观**：总结口诀“求 $X$ 的边缘，就把 $y$ 从头到尾扫一遍（积分）”。配合黑板图形，展示沿着 $y$ 轴方向将曲顶柱体“压扁”到 $x$ 轴上的投影过程。

**难点内容**
- 复杂非矩形区域下，边缘密度的**分段积分区间确定**。

**解决措施**
- **黑板色笔切割法**：在讲解例3求 $f_Y(y)$ 时，画出 $y=x^2$ 和 $y=x+2$ 的图形。用黄色粉笔画出水平扫描线（代表对 $x$ 积分）。直观展示当水平线在 $0 \le y < 1$ 时，穿过的是抛物线的左右两支；当 $1 \le y \le 4$ 时，穿过的是直线和抛物线右支。由此自然引出分段函数的必要性。

## 八、教学方法与教学工具运用
- **教学方法**：降维投影类比法、数理反例证明法（信息丢失）、图像辅助积分法。
- **教学工具**：黑板（核心，用于画出复杂的积分区域和水平/垂直扫描线）、多媒体 PPT（展示三维联合密度被“压平”成一维边缘密度的动画）。

## 九、教学特色与创新
- **信息论视角的升华**：在讲解教材例2（联合分布含参数 $\lambda$，但边缘分布不含 $\lambda$）时，不只停留在数学计算，而是引入信息论观点：边缘分布只包含“个体信息”，联合分布中的 $\lambda$ 则是“纠缠/相关信息”。“降维”必然导致信息的永久丢失。
- **防错口诀化**：针对学生极易犯的错误，强调“算完 $f_X(x)$ 之后，结果里绝对不能再出现字母 $y$！”作为自我校验的标准。

## 十、课前任务设计（教师和学生的教学准备）
- **教师准备**：准备一束手电筒和一个不规则的三维模型（如圆锥），用于课堂上演示“三维物体向二维墙面投影”的物理现象。
- **学生准备**：复习上一节例2的区域图形（抛物线与直线的交点），并复习高等数学中“求截面面积”的定积分应用。

## 十二、过程性评价（设计评价细则与课程目标对应关系图）

**1. 课堂提问清单（对应知识/素质目标）**
- **提问1**：“如果二维随机变量 $(X,Y)$ 分布在一个半径为 $R$ 的圆内。我们在求 $f_X(x)$ 的时候，积分上下限是 $-\infty$ 到 $+\infty$ 吗？如果不是，应该是什么？”（考察对隐含积分区域边界的几何转化能力：$y \in [-\sqrt{R^2-x^2}, \sqrt{R^2-x^2}]$）。
- **提问2**：“在医学上，我们有身高（X）和体重（Y）的联合分布。如果我们只知道全国男性的平均身高分布和平均体重分布（边缘分布），我们能反推出身高和体重之间的相关关系吗？”（考察对边缘分布丢失联合信息的直观理解）。

**2. 当堂小测验（对应能力目标）**
- **测验题**：已知 $(X, Y)$ 的联合概率密度为 $f(x,y) = \frac{1}{8}(x+y) \ (0 \le x \le 2, 0 \le y \le 2)$，其余为 0。求边缘密度 $f_X(x)$。（**考察点**：最基础的矩形区域边缘密度计算，检验对另一个变量积分的基本功）。

## 十三、课后作业

**【基础巩固题】（必做，熟练掌握基本概念与基本积分）**
1. **（概念辨析）** 设二维随机变量 $(X,Y)$ 的边缘密度分别为 $f_X(x)$ 和 $f_Y(y)$。如果有人告诉你它们的联合密度就是 $f(x,y) = f_X(x) \cdot f_Y(y)$，这句话在所有情况下都成立吗？为什么？（结合例2思考）。
2. **（离散边缘分布）** 设二维离散随机变量 $(X,Y)$ 的联合分布律为：
   $P(X=1, Y=1) = 0.2, P(X=1, Y=2) = 0.3$
   $P(X=2, Y=1) = 0.1, P(X=2, Y=2) = 0.4$
   分别求 $X$ 和 $Y$ 的边缘分布律。
3. **（矩形区域边缘密度）** 设 $(X,Y)$ 的联合密度为 $f(x,y) = c e^{-(x+2y)} \ (x>0, y>0)$，其余为 0。
   (1) 求常数 $c$；(2) 求边缘密度 $f_X(x)$ 和 $f_Y(y)$。
4. **（三角形区域边缘密度）** 设 $(X,Y)$ 的联合密度为 $f(x,y) = 2 \ (0 < x < y < 1)$，其余为 0。
   求边缘概率密度 $f_X(x)$。（注意：画出图形，确定对 $y$ 积分时的上下限）。

**【能力提升题】（选做，圆域积分与物理背景）**
5. **（激光斑边缘分布）** 续上一节作业：激光打在感光底片上，光子落点 $(X,Y)$ 在单位圆 $x^2 + y^2 \le 1$ 内服从均匀分布，即 $f(x,y) = 1/\pi$。
   (1) 求 $X$ 的边缘概率密度 $f_X(x)$。
   (2) 证明：虽然光子在圆内是均匀分布的，但如果我们只看 $X$ 轴（例如放置一个单维狭缝光栅），其概率密度不是均匀分布，而是中间高两边低的“半椭圆”形状。
6. **（区域受限的复杂分段）** 设 $(X,Y)$ 的联合密度为 $f(x,y) = 6x \ (0 < x < y < 1)$，其余为 0。
   求 $Y$ 的边缘密度 $f_Y(y)$。（注意：水平线穿过区域时，$x$ 的下限和上限分别是什么？）

**【素养拓展题】（选做，编程验证与数据处理）**
7. **（用 Python 验证联合分布与边缘分布的关系）**
   **任务**：使用 Python 的 `numpy.random.multivariate_normal` 函数，生成 10,000 个具有强相关性（如协方差矩阵为 `[[1, 0.9], [0.9, 1]]`）的二维正态分布随机点。
   (1) 绘制这 10,000 个点的二维散点图（Scatter plot）。
   (2) 提取所有点的 X 坐标，绘制 X 的直方图（Histogram），验证其是否为一维正态分布（即边缘分布）。
   (3) 思考：如果你只把 X 的直方图和 Y 的直方图交给别人，他们能猜出散点图是呈现倾斜的椭圆状（强相关）的吗？

### 【附录：课后作业参考答案】
1. 不一定成立。只有当 $X$ 和 $Y$ 相互独立时（见2.12节）才成立。通常情况下，联合分布包含了相关性信息，不能简单等于边缘分布的乘积。
2. $X$ 的边缘：$P(X=1) = 0.2+0.3 = 0.5$；$P(X=2) = 0.1+0.4 = 0.5$。
   $Y$ 的边缘：$P(Y=1) = 0.2+0.1 = 0.3$；$P(Y=2) = 0.3+0.4 = 0.7$。
3. (1) $\int_0^\infty \int_0^\infty c e^{-x} e^{-2y} dxdy = c(1)(\frac{1}{2}) = 1 \Rightarrow c = 2$。
   (2) $f_X(x) = \int_0^\infty 2 e^{-x-2y} dy = 2e^{-x} [-\frac{1}{2}e^{-2y}]_0^\infty = e^{-x} \ (x>0)$。
   同理 $f_Y(y) = \int_0^\infty 2 e^{-x-2y} dx = 2e^{-2y} \ (y>0)$。
4. 画图：区域为 $y=x$ 上方，$y=1$ 下方的三角形。求 $f_X(x)$，对 $y$ 积分。垂直画线，穿入点为 $y=x$，穿出点为 $y=1$。
   $f_X(x) = \int_x^1 2 dy = 2(1-x) \ (0 < x < 1)$。
5. (1) 圆域内 $x \in [-1, 1]$ 时，对于固定的 $x$，$y$ 的范围是 $[-\sqrt{1-x^2}, \sqrt{1-x^2}]$。
   $f_X(x) = \int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}} \frac{1}{\pi} dy = \frac{2}{\pi} \sqrt{1-x^2} \ (-1 < x < 1)$。
   (2) 该函数在 $x=0$ 时取得最大值 $2/\pi$，在 $x=\pm 1$ 时为 0，形状为一个半椭圆，显然不是均匀分布。
6. 求 $f_Y(y)$，对 $x$ 积分。水平画线，穿入点为 $x=0$，穿出点为 $x=y$。由于图形在 $0<y<1$ 内，
   $f_Y(y) = \int_0^y 6x dx = [3x^2]_0^y = 3y^2 \ (0 < y < 1)$。
7. 略（评价标准：散点图应呈现右上倾斜的椭圆分布；边缘 X 直方图应呈现标准的一维钟形正态分布曲线；结论：仅凭边缘直方图无法推断出散点图的倾斜相关性）。
