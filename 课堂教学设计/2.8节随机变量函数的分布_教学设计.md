## 三、教学理念
秉持“数学是物理变换的底层逻辑”的教学理念。天文学与物理学中充满了坐标变换与变量代换（如从速度分布推导动能分布、从频率推导波长）。本节课旨在帮助学生建立“随机变量函数”的实质即“概率测度的空间转移”这一深刻认知，引导学生通过最基础的“分布函数法（CDF方法）”以不变应万变，培养严密的数学推演与物理直觉相结合的建模能力。

## 四、教学目标
**1、知识目标**
- 掌握**离散随机变量函数** $Y=g(X)$ 的概率分布求法（特别是当函数值有重复时的概率合并）。
- 熟练掌握求**连续随机变量函数**概率密度 $f_Y(y)$ 的通用方法——**分布函数法（CDF法）**，即先求 $F_Y(y) = P(g(X) \le y)$，再对 $y$ 求导。
- 掌握严格单调函数下的**概率密度变换公式** $f_Y(y) = f_X(h(y)) |h'(y)|$。

**2、能力目标**
- 提升学生的**数理转化能力**，能够准确地将物理量（如速度、直径）的概率密度，转化为其导出物理量（如动能、面积）的概率密度。
- 强化学生处理**非单调函数映射**（如 $Y = \sin X, Y = X^2$）时的分段积分与求导技巧。

**3、素质目标**
- 借助物理学中从“麦克斯韦速率分布”推导“分子动能分布”的案例，培养学生认识到自然规律在数学坐标变换下的内在一致性。
- 通过严谨的分段与绝对值讨论，培养学生在科研工作中**严谨、细致的数理逻辑素养**。

## 五、学情分析
- **专业背景**：授课对象为大二理科生，微积分功底扎实，对复合函数求导、定积分换元法非常熟练。
- **知识基础**：在前几节已深入理解了概率密度 $f(x)$ 和分布函数 $F(x)$ 的关系（导数与积分的关系）。
- **认知难点**：
  1. 在连续变量变换公式中，学生往往不理解为什么会出现**导数的绝对值 $|h'(y)|$**（容易忽略单调递减导致积分上下限反转的问题）。
  2. 对于非单调函数（如 $Y=\sin X$），学生在确定积分区间 $\Delta_i(y)$ 时容易找错边界。

## 六、教学内容
1. 随机变量函数概念的引入（以轴的直径与截面积的物理关系为例）。
2. 离散型随机变量函数的分布求法（直接映射与相同值合并）。
3. 连续型随机变量函数分布的通用解法——**分布函数法（CDF法）**（核心重点）。
4. 线性变换 $Y=aX+b$ 的密度推导与绝对值 $|a|$ 的产生原因。
5. 非单调连续变换 $Y=\sin X$ 的分段积分求解演示。

## 七、教学重点及难点
**重点内容**
- 连续随机变量函数的**分布函数法（CDF法）** $F_Y(y) = P(g(X) \le y)$。
- 映射后新变量 $Y$ 取值范围的确定。

**解决措施**
- 强调“万能公式”：无论函数多复杂，第一步永远是写出 $F_Y(y)$ 的定义，将其转化为 $X$ 的不等式，坚决反对学生死记硬背公式。

**难点内容**
- **导数绝对值 $|h'(y)|$** 的物理/几何意义解释。
- 处理非单调函数映射时的积分区间划分（如 $Y=\sin X$ 产生的多段区间）。

**解决措施**
- **几何直观法**：利用黑板作图，当 $g(x)$ 递减时，不等式 $g(X) \le y$ 等价于 $X \ge h(y)$，积分下限变为 $h(y)$，求导产生负号，从而自然引出绝对值。
- **投影作图法**：针对 $\sin X$，画出函数图像，在 $y$ 轴画一条水平线，投影到 $x$ 轴找交点，直观展示积分区间的两段性。

## 八、教学方法与教学工具运用
- **教学方法**：启发式教学法、问题驱动法、物理模型类比法、图像投影法。
- **教学工具**：黑板（推导分布函数法的必用工具，粉笔标出不等式变号的关键步骤）、PPT（展示复杂物理函数变换，如动能分布曲线）。

## 九、教学特色与创新
- **口诀化记忆**：为 CDF 法总结三步口诀：“**一找范围，二写分布，三求导数**”，将繁琐的代数推导流程化。
- **物理视角的引入**：将数学上的“换元法积分绝对值”，解释为物理学上的“空间拉伸/压缩率（雅可比行列式的一维退化）”，加深理科生对测度变换的理解。

## 十三、课后作业

**【基础巩固题】（必做，熟练掌握 CDF 法和公式法）**
1. **（离散映射）** 设 $X$ 的概率分布为 $P(X=-1)=0.2, P(X=0)=0.3, P(X=1)=0.5$。求 $Y=X^2+1$ 的概率分布。
2. **（线性变换）** 设 $X \sim U(0, 1)$。求 $Y = 2X + 5$ 的概率密度。
3. **（CDF法训练）** 设 $X$ 服从参数为 $\lambda$ 的指数分布，求 $Y = X^3$ 的概率密度。要求：必须使用“一找范围、二写分布、三求导数”的分布函数法书写完整步骤。
4. **（非单调函数）** 设 $X \sim U(-1, 1)$。求 $Y = |X|$ 的概率密度。（提示：画出绝对值函数图像寻找积分区间）。

**【能力提升题】（选做，物理模型抽象）**
5. **（麦克斯韦速率分布导出）** 物理学中，处于热平衡状态的理想气体分子的速度在某个方向上的分量 $V_x$ 服从正态分布 $N(0, \sigma^2)$，其概率密度为 $f(v_x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{v_x^2}{2\sigma^2}}$。
   分子的平动动能为 $E_k = \frac{1}{2} m V_x^2$。请推导该动能 $E_k$ 的概率密度函数 $f_E(e)$。（注：注意 $V_x$ 映射到 $E_k$ 是非单调的，类似于 $Y=X^2$）。
6. **（逆变换抽样定理证明）** 设连续随机变量 $X$ 的分布函数为 $F_X(x)$（严格单调递增）。令随机变量 $Y = F_X(X)$。请证明：无论 $X$ 服从什么分布，随机变量 $Y$ 永远服从 $[0, 1]$ 上的均匀分布 $U(0, 1)$。

**【素养拓展题】（选做，计算机模拟）**
7. **（利用逆变换生成随机数）** 上述第6题的结论是计算机生成任意分布随机数的核心原理（Inverse Transform Sampling）。
   **任务**：已知计算机语言的 `random()` 函数只能生成 $[0, 1]$ 上的均匀分布随机数 $Y$。若你想生成参数 $\lambda=2$ 的指数分布随机数 $X$，你应该对 $Y$ 进行怎样的数学变换 $X = g(Y)$？
   请推导出该变换公式，并使用 Python 的 `random.uniform(0, 1)` 生成 10,000 个随机数，经过你的变换后，画出其直方图，验证其是否呈现指数衰减的形状。

### 【附录：课后作业参考答案】
1. $Y$ 的可能取值为 $(-1)^2+1=2$, $0^2+1=1$, $1^2+1=2$。即取值 1 和 2。
   $P(Y=1) = P(X=0) = 0.3$。
   $P(Y=2) = P(X=-1) + P(X=1) = 0.2 + 0.5 = 0.7$。
2. $X \in (0, 1)$，则 $Y \in (5, 7)$。公式法：$x = (y-5)/2, |x'| = 1/2$。$f_Y(y) = 1 \times (1/2) = 1/2 \ (5 < y < 7)$。即 $Y \sim U(5, 7)$。
3. $X > 0$，故 $Y > 0$。$F_Y(y) = P(X^3 \le y) = P(X \le y^{1/3}) = 1 - e^{-\lambda y^{1/3}}$。求导得 $f_Y(y) = \lambda e^{-\lambda y^{1/3}} \cdot \frac{1}{3}y^{-2/3}$ (当 $y>0$ 时)。
4. $Y = |X|$ 的范围是 $[0, 1)$。$F_Y(y) = P(|X| \le y) = P(-y \le X \le y) = \int_{-y}^y \frac{1}{2} dx = y$。求导得 $f_Y(y) = 1 \ (0 \le y < 1)$。即 $Y \sim U(0, 1)$。
5. 动能 $E \ge 0$。$F_E(e) = P(\frac{1}{2} m V_x^2 \le e) = P(-\sqrt{\frac{2e}{m}} \le V_x \le \sqrt{\frac{2e}{m}})$。
   由于 $V_x$ 是偶函数，积分后求导（利用变限积分求导法则），结果为 $f_E(e) = \frac{1}{\sqrt{\pi e m}\sigma} e^{-\frac{e}{m\sigma^2}} \ (e > 0)$。
6. $Y$ 的范围是 $[0, 1]$。$F_Y(y) = P(Y \le y) = P(F_X(X) \le y)$。由于 $F_X$ 严格递增，存在反函数，即 $P(X \le F_X^{-1}(y))$。而 $P(X \le x)$ 本身就是 $F_X(x)$ 的定义，故上式等于 $F_X(F_X^{-1}(y)) = y$。分布函数为 $F_Y(y)=y$，其导数为 $1$，证毕 $Y \sim U(0, 1)$。
7. 指数分布的 $F_X(x) = 1 - e^{-\lambda x}$。令 $Y = 1 - e^{-\lambda X}$，反解得 $X = -\frac{1}{\lambda} \ln(1-Y)$。由于 $Y$ 和 $1-Y$ 都是 $U(0,1)$ 分布，所以代码中可以直接用 $X = -0.5 * \ln(Y)$ 来生成。（代码截图略）。
