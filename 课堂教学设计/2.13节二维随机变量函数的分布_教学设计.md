## 三、教学理念
物理世界中的宏观观测量往往是多个微观或基础随机变量的复合（如：总能量是动能与势能之和，信噪比是信号与噪声之商，天文阵列望远镜的寿命取决于各个子镜寿命的极值）。本节课的教学理念是从“单变量映射”走向“多变量复合”，以**“分布函数法（CDF Method）”**为核心武器，将所有求函数分布的问题统一转化为“相空间（积分区域）上的概率测度计算”。通过引入光学成像中的卷积、工程中的可靠性串并联模型，让理科生深刻体会数学工具如何精确刻画物理与工程现象。

## 四、教学目标
**1、知识目标**
- 熟练掌握**分布函数法**（先求 $F_Z(z) = \iint_{g(x,y)\le z} f(x,y)dxdy$，再求导得 $f_Z(z)$），并理解其普适性。
- 掌握独立随机变量之和的**卷积公式**（离散求和与连续积分），并记住泊松分布、正态分布的“可加性”。
- 掌握多个独立随机变量**最大值与最小值**的分布函数推导公式。

**2、能力目标**
- 能够通过“几何扫线法”（画图平移 $x+y=z$ 直线），准确确定分段连续变量卷积积分的上下限。
- 能够利用极值分布（Max/Min）解决复杂的系统可靠性（串联、并联）建模问题。

**3、素质目标**
- 引入光学中的点扩散函数（PSF）卷积和航天器冗余系统设计（如探测器阵列），培养学生将抽象数学公式与尖端科学工程相结合的建模素养和系统思维。

## 五、学情分析
- **专业背景**：授课对象为大二理科生，具备较好的二重积分计算能力和空间几何直觉，且在物理实验中接触过误差传递（本质是随机变量的组合）。
- **知识基础**：已在 2.8 节熟练掌握了一维随机变量函数的分布函数法（“一找范围、二写分布、三求导”），且在 2.12 节掌握了独立性。
- **认知难点**：
  1. **分段积分限的确定**：在计算两个均匀分布相加的卷积（辛普森分布）时，直线 $x+y=z$ 扫过方形区域，积分限随 $z$ 的变化而发生 4 次断裂，学生极易算错。
  2. **极值分布的求导遗忘**：学生在算出 $F_{\max}(z) = [F(z)]^n$ 后，常常忘记求导，直接将其作为概率密度答案提交。

## 六、教学内容
1. **分布函数法的普适框架**（解决任意 $Z=g(X,Y)$ 的根本方法）。
2. **和的分布与卷积公式**：
   - 离散卷积（泊松分布的再生性/可加性）。
   - 连续卷积公式。
   - 重点解析：两个独立均匀分布相加的辛普森（Simpson）分布（三角分布）。
3. **极值分布（Max 与 Min）**：
   - 最大值分布（对应系统并联、冗余设计）。
   - 最小值分布（对应系统串联、木桶效应）。
4. （简略点拨）商的分布与平方和的分布（引导学生课后自学推导）。

## 七、教学重点及难点
**重点内容**
- 连续随机变量和的卷积公式 $f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x)dx$。
- 最大值与最小值的分布函数推导逻辑。

**解决措施**
- **口诀记忆法**：极值分布推导——“最大值，都小于，直接乘”；“最小值，用对立，都大于，乘完减”。

**难点内容**
- 两个有限区间分段函数（如均匀分布）的卷积积分区间划分。

**解决措施**
- **几何动画扫线法**：不依赖纯代数不等式推导，而是借助 PPT 动画，让直线 $x+y=z$ 像扫描仪一样从左下方向右上方移动，通过直线与矩形区域的交点几何特征，清晰直观地划分 $z$ 的四个讨论区间。

## 八、教学方法与教学工具运用
- **教学方法**：统一框架法（分布函数法）、动画扫线法、工程案例驱动法（串并联系统）。
- **教学工具**：黑板（推导极值分布公式，书写卷积积分的上下限代数约束）、PPT（展示 $x+y=z$ 的扫描动画，展示辛普森分布的三角波形，展示串并联电路逻辑图）。

## 九、教学特色与创新
- **方法论的升维统一**：不孤立地讲“和、商、平方和”，而是首先亮出“分布函数法”这把尚方宝剑。强调所有公式（包括卷积）都只是这把剑在特定函数 $g(X,Y)$ 下的推论，培养学生“抓本质、轻套路”的理科思维。
- **“木桶效应”与“备份思想”的数学表达**：将抽象的 Min 分布与社会学/工程学中的“木桶效应（串联）”对应；将 Max 分布与“航空航天关键器件的冗余备份（并联）”对应，赋予数学公式极强的现实生命力。

## 十、课前任务设计（教师和学生的教学准备）
- **教师准备**：制作直线 $x+y=z$ 扫过正方形区域的 PPT 动图；整理天眼望远镜（FAST）接收器阵列或深空探测器并联电池组件的工程案例。
- **学生准备**：复习 2.8 节的一维分布函数法；复习二重积分中“画图定限”的方法。

## 十二、过程性评价（设计评价细则与课程目标对应关系图）

**1. 课堂提问清单（对应知识/能力目标）**
- **提问1**：“已知 $X$ 和 $Y$ 独立，分别服从泊松分布 $P(\lambda_1)$ 和 $P(\lambda_2)$，它们的和 $Z=X+Y$ 服从什么分布？”（考察对离散卷积例题的记忆与结论掌握，答案：泊松分布 $P(\lambda_1+\lambda_2)$，称为再生性）。
- **提问2**：“在求 $Z=X+Y$ 的分布时，如果不独立，还能不能把 $f(x,y)$ 拆成边缘密度相乘再积分？”（考察对独立性前提的敬畏感。答案：绝对不能，必须回到联合密度求二重积分）。

**2. 当堂小测验（对应极值分布求解能力）**
- **测验题**：设有两个独立的传感器，寿命均服从参数为 $\lambda$ 的指数分布。如果将它们**并联**（只要有一个正常，系统就正常）。
  (1) 求系统总寿命 $Z$ 的分布函数 $F_Z(z)$。
  (2) （陷阱！）求系统总寿命 $Z$ 的概率密度 $f_Z(z)$。
  （**考察点**：套用 Max 公式得到 $F(z)$，并检查学生是否记得求导得到密度）。

## 十三、课后作业

**【基础巩固题】（必做，熟练运用卷积与极值公式）**
1. **（离散和的分布）** 设 $X \sim B(n, p)$， $Y \sim B(m, p)$，且 $X, Y$ 相互独立。利用离散卷积公式，推导证明 $Z = X+Y \sim B(n+m, p)$。（物理意义：两个独立的伯努利试验序列合并）。
2. **（不独立情况的和）** 设 $(X,Y)$ 联合密度为 $f(x,y) = 2 \ (0 < x < y < 1)$。求 $Z = X+Y$ 的概率密度 $f_Z(z)$。（提示：不能用卷积公式，必须画图 $x+y \le z$ 计算二重积分）。
3. **（串并联系统寿命）** 设系统由 3 个相同的元件组成，寿命 $X_i$ 独立且均服从均匀分布 $U(0, 1000)$（单位：小时）。
   (1) 若三个元件**串联**，求系统寿命的概率密度。
   (2) 若三个元件**并联**，求系统寿命的概率密度。

**【能力提升题】（选做，天文学信噪比建模）**
4. **（商的分布探究）** 在天文观测中，接收到的信号强度为 $X$，背景噪声强度为 $Y$。假设 $X$ 和 $Y$ 相互独立，且都服从标准正态分布 $N(0,1)$。
   (1) 请参考教材 2.13.2 节的思路，求信噪比 $Z = X/Y$ 的概率密度函数。
   (2) 查阅资料，看看这个没有数学期望的“奇怪”分布在统计学中叫什么名字？（提示：柯西分布）。

**【素养拓展题】（选做，Python蒙特卡洛仿真极值分布）**
5. **（蒙特卡洛验证木桶效应）**
   **任务**：假设你有 100 个串联的电池组件（木桶的 100 块短板），每个组件寿命独立且服从指数分布 $e(1)$（平均寿命为 1）。
   (1) 编写 Python 代码，利用 `numpy.random.exponential` 模拟产生 100 个电池的寿命，并求它们的最小值（即一组系统的寿命）。
   (2) 重复上述实验 10000 次，得到 10000 个系统寿命。绘制其直方图。
   (3) 根据图形直观判断，由 100 个平均寿命为 1 的电池串联而成的系统，其平均寿命大约是多少？这说明了复杂系统串联设计的什么致命弱点？

### 【附录：课后作业参考答案】
1. $P(Z=k) = \sum_{i=0}^k P(X=i)P(Y=k-i) = \sum_{i=0}^k C_n^i p^i (1-p)^{n-i} C_m^{k-i} p^{k-i} (1-p)^{m-(k-i)} = p^k (1-p)^{n+m-k} \sum_{i=0}^k C_n^i C_m^{k-i}$。
   利用范德蒙德卷积恒等式 $\sum_{i=0}^k C_n^i C_m^{k-i} = C_{n+m}^k$，得 $P(Z=k) = C_{n+m}^k p^k (1-p)^{n+m-k}$。得证。
2. $F_Z(z) = \iint_{x+y \le z, 0<x<y<1} 2 dx dy$。
   当 $z<0$ 时，$F_Z(z)=0$；当 $0 \le z \le 1$ 时，$F_Z(z) = z^2/2$；当 $1 < z \le 2$ 时，$F_Z(z) = 1 - (2-z)^2/2$；当 $z>2$ 时，$F_Z(z)=1$。
   求导得：$f_Z(z) = z \ (0 \le z \le 1)$；$f_Z(z) = 2-z \ (1 < z \le 2)$；其他为0。
3. $F(x) = x/1000 \ (0 \le x \le 1000)$。
   (1) 串联为 Min。$F_{\min}(z) = 1 - (1 - z/1000)^3$。求导：$f_{\min}(z) = \frac{3}{1000}(1 - z/1000)^2 \ (0 \le z \le 1000)$。
   (2) 并联为 Max。$F_{\max}(z) = (z/1000)^3$。求导：$f_{\max}(z) = \frac{3z^2}{1000^3} \ (0 \le z \le 1000)$。
4. (1) 根据公式 (2.90)：$f_Z(z) = \int_{-\infty}^{+\infty} |y| \frac{1}{2\pi} e^{-y^2 z^2 / 2} e^{-y^2 / 2} dy = \frac{1}{\pi} \int_0^{+\infty} y e^{-y^2(z^2+1)/2} dy = \frac{1}{\pi(1+z^2)}$。
   (2) 这是标准的柯西分布（Cauchy Distribution）。
5. (1) (2) 略（Python 模拟）。
   (3) 理论上 $\min \sim e(100)$，平均寿命仅为 $1/100 = 0.01$！说明元件越多，串联系统越容易崩溃，必须引入冗余（并联）设计。
